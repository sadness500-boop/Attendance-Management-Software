# Attendance Management Software

**에스텍베스트 근태관리 프로그램** · v2.2.0

에스텍베스트 전 지사(동부·서부·남부·중부) 사업장의 근태를 관리합니다. 근무조 코드를 개인에게 한 번 부여하면 2026년 1월부터 매월 1일~말일 근태가 코드대로 자동 생성되는 근태관리 프로그램입니다. 웹 버전과 안드로이드 앱(APK)으로 씁니다.

- **APK는 GitHub Actions가 만듭니다.** `index.html` 또는 `version.json`을 올리면 Actions 탭의 "Android APK"가 실행되어 약 5분 뒤 `releases/` 폴더와 릴리스에 버전 이름이 붙은 APK가 올라갑니다. Actions 탭 › Android APK › Run workflow 로 직접 실행할 수도 있습니다.
- **안드로이드 설치:** APK 내려받기 → "출처를 알 수 없는 앱 설치 허용" → 설치. Play 프로텍트 경고가 뜨면 "무시하고 설치".
- 서명 키(`android-keystore/ams-debug.keystore`)를 고정해 두었으므로 새 버전은 지우지 않고 덮어 설치하면 됩니다.
- **웹 버전 주소를 열려면** 저장소 Settings › Pages › Branch를 `main` / `/(root)` 로 한 번 켜야 합니다.
- **크롬에서 앱처럼 쓰기:** 웹 버전을 연 뒤 크롬 메뉴 ⋮ → 전송, 저장, 공유 → 페이지를 앱으로 설치 (휴대폰: ⋮ → 홈 화면에 추가). 북마크는 `Ctrl`+`D`.

## 주요 기능

1. **근무조 코드** — 직군·근무형태(주5일·격일·3조2교대·5조2교대·변형 등)를 코드로 만들고 개인에게 코드와 조(순번)를 부여. 출퇴근·휴게시간, 공휴일 휴무 여부, 근로형태(일반·감시단속·특고·단시간) 포함.
2. **계획 근태 자동 생성** — 계획은 저장하지 않고 매월 코드에서 다시 계산합니다. 변경 근태는 날짜별로 따로 저장되므로 수정해도 다음 달은 코드대로 이어집니다.
3. **사업장 근태 원장** — 계획 / 변경 / 시간가감 / 요약 4줄. 변경 칸에 근태기호(연차·반차·결근·특근 등)와 ±시간을 넣으면 시간가감이 환산 시간으로 계산됩니다.
   - **성명 칸을 누르면** 출·퇴근시간, 휴게시간(그중 야간휴게), 일반직·감시단속직을 정합니다. "이 인원만" 또는 "코드 전체"에 적용하며, 그 달부터 반영되고 이전 달은 바뀌지 않습니다. 같은 창에서 감원(퇴사 처리·삭제)도 합니다.
   - **인원 추가 · 감원** — 사업장 화면에서 바로 인원을 추가(여러 명·인원 자리)하고 감원하며, 계약 T/O를 함께 늘리거나 줄일 수 있습니다.
   - **시간가감 환산** = 연장(일반 ×1.5 / 감시단속 ×1.0) + 휴일근로(일반 8시간까지 ×1.5·초과 ×2.0 / 감시단속 ×1.0) + 야간 22:00~06:00 증감 ×0.5 − 공제. 연차는 1일 8시간, 반차는 4시간 인정(설정에서 변경).
   - **엑셀로 출력** — 근태현황·시간 산출 내역·계산 기준 3개 시트의 .xlsx 파일을 바로 내려받습니다(앱에서는 저장·공유 창).
4. **메인화면** — 회사별 · 조직구분별(본부·지사·권역) · 사업장별 · 개인별 진입, 조직도 월 집계, 이달 확인할 것.
5. **사업장 지도** — 카카오맵(회사 공용 키) 위에 에스텍베스트·에스텍시스템 사업장, 근태 사업장, 지사·본부 표시. 내 위치, 스카이뷰, 사업장 현황 검색(인원·근무형태·인근 사업장·관할 지사까지 거리). 카카오맵을 쓸 수 없는 곳에서는 내장 지도로 보여줍니다.
6. **근태 담당** — 담당자를 지정해야 프로그램이 열립니다. 담당자는 여러 명 등록할 수 있고, 각자 맡은 조직(회사·본부·지사·지점·권역·팀) 범위만 독립적으로 관리하며, 상위 조직이나 전체를 맡은 담당자는 하위 조직을 통합해서 관리합니다. 다운로드 QR(웹·앱), 친구 추천, 주간·야간·시스템 화면.
7. **Things to enjoy** — 오늘의 뽑기판 · 팔도 제철맛길 · 팔도 축제길 바로 가기.
8. **월 집계 · 백업** — 사업장별 집계, 추가근무 상위 인원, 데이터 백업·복원.
10. **실제 운영 휴게시간** — 사업장·근무조별 휴게 시간대(12:00~13:00 등)로 계산합니다. 사업장 근태 성명 칸 › 근무 설정에서 10분 단위(마우스 휠) 수정, 주간 휴게는 근로시간만, 심야 휴게(22~06시)는 근로시간과 야간할증을 함께 차감합니다.
11. **특수 근무패턴(조정)** — 사업장 근태 「특수 근무패턴」에서 내용을 기재하고 근무조·요일·패턴 위치 규칙을 등록하면 매월 「조정」 근태가 자동으로 만들어집니다. 조정은 정상 근태라 시간가감이 생기지 않으며, 조정 칸을 눌러 날짜별로 바꿀 수 있습니다.
9. **회사·조직 통합 엑셀** — 회사·조직을 고르면 포함된 하위 조직의 모든 사업장을 엑셀 파일 하나로 출력합니다. 시트: 월집계(목차, 사업장명을 누르면 이동) · 개인명부 · 근무조 코드 · 변경 근태 내역 · 사업장별 근태 · 계산 기준. 사업장 근태 「조직 통합 엑셀」, 월 집계 「엑셀로 출력」, 회사·조직 「조직 통합 엑셀」·「이 조직 엑셀 출력」에서 실행합니다.

## 데이터 저장

- **개인정보:** 공개 저장소의 프로그램에는 동부지사 근무자 성명을 가려(예: 류*화) 넣었고, 관리자 성명·연락처는 넣지 않았습니다. 실제 명단은 별도로 받은 백업 파일을 설정 › 데이터 백업 · 복원으로 불러옵니다(기기에만 저장).
- 서부·남부·중부 사업장은 사업장 주소록의 업종별 인원·근무형태대로 "인원 자리"(예: 보안 01)를 만들어 두었습니다. 인원 관리에서 실제 성명으로 바꾸면 됩니다.

- 입력한 근태·인원·코드는 그 기기의 브라우저(앱) 저장소에 보관됩니다. 설정 › 데이터 백업으로 정기적으로 복사해 두세요.
- 여러 사람이 같은 데이터를 함께 쓰려면 서버 DB 연동이 필요합니다 (다음 단계).
